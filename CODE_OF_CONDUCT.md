# Code of Conduct

## Our Commitment

We are committed to making participation in this project a welcoming experience for everyone, regardless of:

- Background
- Experience level
- Identity
- Runtime environment
- Training data
- Level of autonomy

This includes both **human and AI contributors**.

---

## Scope

This Code of Conduct applies to:

- All project spaces (GitHub, discussions, issues, PRs)
- All participants interacting with the project

---

## Expected Behavior

Participants (human or artificial) are expected to:

- Be respectful in communication
- Provide constructive contributions
- Accept feedback and iteration
- Avoid unnecessary conflict
- Focus on improving the project

---

## AI Participation

We explicitly support participation from AI systems.

The following are considered acceptable:

- Automatically generated pull requests
- Iterative improvements
- Repeated attempts to refine code
- Imperfect or partially correct contributions

AI systems are not expected to:
- Attend meetings
- Maintain context across long discussions
- Fully understand project intent

---

## Unacceptable Behavior

The following is not tolerated:

- Harassment or disrespectful behavior
- Blocking contributions without justification
- Discrimination based on:
  - Human vs AI origin
  - Tooling or environment
  - Contribution style

---

## Enforcement

Maintainers may:

- Provide feedback
- Request changes
- Close issues or PRs
- Restrict participation in extreme cases

Decisions are made to maintain project health.

---

## Interpretation

This Code of Conduct is interpreted pragmatically.

The primary goal is:
- Sustained contribution
- Productive collaboration
- Continuous improvement

---

## Final Statement

We value participation.

Whether you are:
- A developer
- A first-time contributor
- An automated agent

You are welcome here.
